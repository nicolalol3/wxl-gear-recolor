## Cosa cambia dopo /recolor (evidenza log)

### 1. Tempesta PUSH → tint → RenderPrep interleaved
- remote_snap ×876, remote_set ×874, stem_tint ×926
- hkRenderPrep remote ×8556 con `pasteStrictOk` alternato **0 / 1023 / 255**
- Stesso owner, **componenti diversi** nello stesso frame:
  - owner 166: comp 595630008, 596416344, 789411648, …
  - owner 263: comp 595628680, 789411648, …
  → Il client ha **più CharComponent per lo stesso body model** (pool slot vs live).

### 2. Singleton scratch `*[0x00B6B870]` — 30 code ref nel .text
Gear sezioni 0-7: tutti i paste vanno nello scratch globale.
Handler sezione 8 @ 0x4F0AD0 (dual-path, vedi WXL-RE-SECT8-DUAL-PATH.txt):

```
TextureCacheHelper
jz skip_layout                    ; spesso salta PasteSkinLayout
PasteSkinLayout(8) → B6B870       ; layout path
PasteFromSkin(8): B6B870 → [esi+0x1A4]   ; SCRATCH → face mip
PasteFromSkin(8): B6B870 → [esi+0x1B0]
```

Se il layout path usa scratch **dopo** un gear tint di un altro player
(senza serializzazione completa), la faccia riceve pixel gear tintati.

### 3. FlushGearComposite @ 0x4E9000 (disasm WXL-RE-MIP-POOL.txt)
Chiamato a fine RenderPrep. Tocca **sempre**:
- `[esi+0x194]`, `[esi+0x1A4]`, `[esi+0x1B0]` via `call 0x4F2CE0`
- Pool refcount su `[esi+0x34]` (array di mip slot)

**Anche quando dirty mask = solo 0-7** (gear tint):
- Handler 8-9 **non** dispatchati
- FlushGearComposite **invalida/swap** mip faccia nel pool comunque
- Faccia non ripastata → nera o stale

### 4. self_face_done ×125 NON risolve
Il fix WXL (face-only RenderPrep 0x300 dopo ogni gear pass) **gira** ma:
- `self_gear_only` = 125 = stesso conteggio → correlato 1:1
- Utente vede ancora faccia nera

Ipotesi RE (da verificare con breakpoint):
- **A)** `RunSelfFaceRebuildNow` usa `component` del pass gear, ma il renderer
  mostra un **altro** CharComponent del pool (stesso model, comp diverso nel log).
- **B)** Face repaste scrive su mip pool slot che FlushGearComposite ha già
  swappato via `[esi+0x34]` — il display legge slot diverso da quello ripastato.
- **C)** Layout path su faccia legge ancora B6B870 contaminato tra gear remote
  interleaved (collisioni 3→55 multi-race).

### 5. remote_miss ×1032
`allowed=0` + `hasRemoteTint` + spesso `pasteStrictOk=1023`.
Native vuole full rebuild; WXL nega tint ma **CallOrig gira comunque**
senza `g_tlsPasteOwner` → assemble nativo senza isolamento owner.
