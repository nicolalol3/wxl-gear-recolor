  CGUnit_C* (player/NPC)
    +0xB4  body model root (verified by WXL runtime: ComponentModel == unit+0xB4)

  CharComponent* (per visible character body composite)
    +0x38  bodyModelPtr — MUST match unit+0xB4 for correct owner binding

    OTHER PLAYERS: pool base *[0x00B6B240], stride 0x198 slots

## 2. SHARED (GLOBAL) vs PER-UNIT (ISOLATED)

| Resource | Address | Scope | Risk for recolor |
|----------|---------|-------|------------------|
| Paste scratch mips | *[0xB6B870] | **ONE for entire client** | Gear paste writes here; last writer wins before flush |
| TextureCache root | *[0xB6B864] | **ONE global cache** | CPU pixel buffers shared; tint must be per-owner |
| Section dispatch ptr | *[0xB6B88C] | Global ptr to handler table | Read-only at runtime |
| CharComponent composites | [comp+0x194..] | **Per unit** | Safe if comp bound correctly |
| sectionDirty mask | [comp+0x0C] | **Per unit** | WXL must not set 8-9 on gear-only pass |
| Mip pool ring | [comp+0x34] | **Per unit** | FlushGearComposite swaps ALL slots incl face |
| bodyModelPtr | [comp+0x38] | **Per unit** | Identity key: must == unit+0xB4 |

ROOT CAUSE OF CROSS-PLAYER BLEED:
  Client assumes single-threaded assemble: writes gear to B6B870, then
  FlushGearComposite(comp) copies scratch → THAT comp's mips.
  If two RenderPrep interleave OR scratch still has player-A pixels when
  player-B's face handler reads B6B870 → face gets wrong texture.

## 3. ASSEMBLE PIPELINE (pseudocode)

```
RenderPrep(CharComponent* comp, model*, int a2) @ 0x4F1520
  if [comp+0x3C] NPC → early out
  if [comp+0x0C] == 0 → early out
  RenderPrepSections(comp) @ 0x4EE0D0
    mask = [comp+0x0C]
    for bit in 0..9:
      if mask & (1<<bit):
        handler = table[bit]  ; hardcoded cluster 0x4F09D0..0x4F0E40
        handler(comp)
    [comp+0x0C] &= ~processed_bits
  FlushGearComposite(comp) @ 0x4E9000  ; ALWAYS runs if gear dirty path
    RefCountCompositeMip([comp+0x194])
    RefCountCompositeMip([comp+0x1A4])  ; FACE even if sec8 not dirty!
    RefCountCompositeMip([comp+0x1B0])  ; FACE
    RefCountCompositeMip([comp+0x1C0])
    → publishes mip pool slot for GPU
```

## 7. RULES FOR WXL RECOLOR (derived from RE, NOT guesses)

R1 IDENTITY: Never tint without verified CharComponent* where
   ComponentModel(comp) == unit(owner)+0xB4.

R2 SCRATCH SERIALIZATION: Only ONE assemble may use B6B870 at a time
   across ALL players (mutex for entire RenderPrep+Flush window).

R3 DIRTY MASK: Remote tint must set ONLY bits 0-7 (0xFF).
   Bits 8-9 (0x300) trigger face handlers that read stale B6B870.
   Login uses 0x3FF once per player sequentially — safe natively.
   /recolor PUSH forces 0x3FF on remotes while scratch has gear tint.

R4 FACE IS NOT GEAR: Section 8-9 handlers paste ITEM textures onto
   face composite mips (+0x1A4/+0x1B0/+0x1A0) when ItemDisplayInfo
   maps to those sections. Blocking must happen IN PasteFromSkin when
   dst is face field AND src is item gear texture.

R5 FLUSH IS PER-COMPONENT: FlushGearComposite cannot be skipped for
   remotes (invisible model). It cannot be naively save/restored
   (refcount crash). Must ensure scratch is correct BEFORE flush.

R6 LOCAL VS REMOTE:
   Self:  comp = *[B6B1A0], separate from pool
   Remote: comp = pool[slot], stride 0x198
   Same pipeline, different comp pointer — isolation is comp-level.

R7 NATIVE-FIRST: Remote's first 0x3FF assemble after spawn must
   complete untinted before any WXL gear tint (g_remoteNativeDone).
